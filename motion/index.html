Motion Library

Reference patterns for adding motion to Summit sites. Each example is a single HTML file you can open directly, read in a minute, and hand to Claude as the pattern to copy. Shared timing and easing tokens live in shared/motion.css; the rules Claude follows live in AGENTS.md.
