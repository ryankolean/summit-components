Shared-element transitions

Click a tile. The card morphs into the detail view using document.startViewTransition(). Browsers without support swap instantly, so nothing breaks.

Flavor

Same-document view transitions work for SPAs. For multi-page sites add @view-transition { navigation: auto; } to both pages and give matching elements the same view-transition-name.
